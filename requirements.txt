# Direct dependencies, pinned to exact versions.

# These were previously `>=` with no upper bound, which is a latent build
# failure: the Dockerfile pip-installs this file, so a rebuild silently picks up
# whatever is current. That already broke — azure-mgmt-resource 26.0.0 dropped
# the top-level `ResourceManagementClient` re-export, so a fresh image would
# crash on import while the running container (built against an older release)
# stayed healthy.
#
# Transitive dependencies are NOT locked here. If the image build needs to be
# fully reproducible, generate a lock with `pip freeze` in a clean venv.
#
# To upgrade: bump deliberately, run `pytest tests/`, and confirm `python -c
# "import app"` still succeeds.
